# 🌤️ Weather App

A simple GUI-based Python Weather Application that allows users to select a location and view its current weather information using the OpenWeatherMap API.

## Features

* **Location Selection:** Select a location from a predefined list of Indian states.

* **Weather Information:** Displays the current weather condition for the selected location.

* **Weather Description:** Shows a detailed description of the current weather.

* **Temperature:** Displays the temperature in Celsius.

* **Pressure:** Displays the current atmospheric pressure.

* **Simple GUI:** User-friendly graphical interface built using Tkinter.

* **API Integration:** Fetches real-time weather information using the OpenWeatherMap API.

## Requirements

* Python 3.x
* Tkinter
* Requests
* OpenWeatherMap API Key

## How to Run

1. Clone the repository or download the source files.

2. Open your terminal in the project directory.

3. Install the required library:

```bash
pip install requests
```

4. Run the application:

```bash
python main.py
```

## How It Works

1. **Select Location:** Choose a location from the dropdown menu.

2. **Click Done:** Click the **Done** button to request the weather information.

3. **API Request:** The application sends the selected location to the OpenWeatherMap API.

4. **Get Weather Data:** The API returns the current weather information.

5. **Display Results:** The application displays:

   * Weather condition
   * Weather description
   * Temperature in Celsius
   * Atmospheric pressure
